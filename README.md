# SPHEREx Sky Explorer

## Overview

SPHEREx Sky Explorer is a public-facing web application designed to help users explore how regions of the infrared sky change over time.

The application accepts Right Ascension and Declination coordinates and displays multiple observations of the selected region.

Users can compare observations to look for:

- Moving objects
- Variable stars
- Brown dwarfs
- Asteroids
- Comets
- Other changing astronomical sources

---

## Main features

### 1. Coordinate search

Users can enter:

- Right Ascension
- Declination

Coordinates are provided in decimal degrees.

---

### 2. Known astronomical targets

The application includes example targets:

- Barnard's Star
- Epsilon Indi B
- WISE 0855
- RW Aurigae
- R Draconis
